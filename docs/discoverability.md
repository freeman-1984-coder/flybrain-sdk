# Search and AI discoverability

The public GitHub repository and GitHub Pages documentation give people and search
systems crawlable descriptions, working examples, API names and model limitations.
Pages uses static HTML, meaningful titles/descriptions, canonical URLs, a sitemap,
structured SoftwareSourceCode data, and visible source/contribution links. Repository
topics describe the actual project. `llms.txt` is a convenience index for tools,
not a Google ranking requirement or guarantee.

After publication, an owner can verify the Pages URL-prefix property in Google
Search Console, submit the sitemap and inspect indexing. Account-bound verification
may require the owner's session. Search engines decide whether and when to index;
new pages do not receive a guaranteed ranking. Google describes the same foundations
of crawlability and helpful content for AI search features:
[official guidance](https://developers.google.com/search/docs/appearance/ai-features).

Useful ongoing work: publish measured examples, document real-data imports, link
from genuine related projects with permission, respond to issues, and keep API
examples accurate. Do not buy spam links, fake stars, or promise top search positions.
