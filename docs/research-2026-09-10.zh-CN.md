# 从推特玩法到通用 Demo SDK：补充调查与实施决定

核查日期：2026-09-10。这是有目的的项目样本，不是社区全量统计。作者帖子说明创作意图，仓库说明可检查的实现；本项目没有运行或复现这些第三方项目的学习、性能结果。

## 这次新增核实了什么

之前的 RFC 0001 主要依靠索引定位 Beat Saber。此次直接在 X 原帖读取了作者的后续说明，也读取了 Mario 原帖、Minecraft 作者主页与发布说明，并交叉查看公开项目文档。

| 玩法 | 可核实的实现边界 | 我们应公共化的部分 |
| --- | --- | --- |
| 双刀切方块 / Beat Saber | 作者说明针对一首曲目，输入仍混有示范回放，正在降低 teacher forcing；未找到可检查的训练源码 | 观测、示范输入、训练与评估分别记录，支持连续姿态输出 |
| Mario 64 | 视觉采样进入神经模型，读出转换成摇杆与短时按键；桥接还处理事件确认与过期释放 | 图像编码、连续控制、一次性事件、时间同步、接收确认 |
| Minecraft / NeuroCraft | 作者已公布项目主页，准备代码和可玩 mod；不能把另一 Minecraft 仓库当成它的源码 | 世界事件到神经输入、脑输出到身体动作、版本化环境适配 |
| 另一 Minecraft 实现 | 项目明确标出人工寻食兜底、飞行状态机及神经读出 | 可关闭的辅助控制器，同时显示原始神经命令和实际动作 |

## 产品决定：把“接线和开发工具”做完整

根据这些样本，我判断开发者需要的公共部分是：加载模型后，不必重复处理输入转换、群体筛选、时钟、输出解码、环境反馈、检查点和可分享的演示。我们不应把所有玩法写成内核里的固定动作。

面向新手提供可修改的默认配方；向有经验的开发者开放相同的组件。建议保持三种深度：

1. **改配置**：修改输入增益、输出权重、神经细胞选择和模拟周期。
2. **换组件**：用自己的 `encode()`、`decode()`、环境或身体适配器，保持相同 Session。
3. **换模型实现**：保留原始神经元 ID、图与参数来源；通过独立动力学协议接其他模拟器。设备选择只负责执行位置，不能把 tanh reservoir 混称成 LIF。

连接组数据、模拟参数、感觉/动作配方、训练后的读出应成为不同版本的资产。社区应能只贡献一个编码器、一个模型转换配方或一个 demo，而无需修改整个 SDK。

## 快速上手：本次落地

`v0.4.0a2` 增加安装包内的命令入口，生成项目不需要再复制仓库 examples：

```sh
flybrain doctor
flybrain demos list
flybrain init my-fly --template dodge
cd my-fly
python app.py --output runs/first
```

生成 `app.py`、`recipe.json`、依赖版本、说明、MIT 许可与模型归属说明。输入映射和输出读出在配方里可直接编辑；环境组装在普通 Python 文件里。再次运行到新目录即可比较修改前后的结果。也可选择 `tones`，或显式下载真实 MaleCNS 小回路生成对应配方。

`flybrain demos run tones --output work/tones` 可直接生成经过反馈回放验证的音频 demo。导出的 HTML 是记录查看器；现有 circuit lab 才是浏览器实时神经仿真。我们还没有把记录查看器称为实时游戏，也没有把发声称为学会音乐。

## 接下来按用户价值排序

| 次序 | 具体交付 | 验收方法 |
| --- | --- | --- |
| 1 | 用 Session 做一个实时可交互的 2D 场景；编辑配方、暂停、单步、重置可直接看到变化 | 人工改变场景后，新观测影响神经状态和实际动作；关掉输出后运动变化；无旧录像冒充现场 |
| 2 | 通用事件和控制适配：连续轴、短时按钮、序号、有效期、应用确认；优先接一个引擎 | 不丢单次事件，不重复按键；延迟/断开时释放控制；实际动作有记录 |
| 3 | 音频输入特征、平滑/阈值读出、固定脑可训练输出层 | 用未见音频/速度或谱面测试；同时跑输入直达输出、静默脑和打乱连接对照 |
| 4 | Demo 配方目录与社区提交流程 | 提交一个小配方即可运行、生成归属说明和可分享结果；不要求复制内核 |

CUDA 分支独立推进实际 NVIDIA 验证。它能帮助规模和训练吞吐，但不能代替上手、调试和环境适配。当前租卡流程已准备，尚未启动收费资源；没有 GPU 实测通过就不宣传已支持。

官网按开发任务组织入口：Python connectome simulation、game integration、audio sonification、MaleCNS model download。每个入口给实际可运行命令、源码和准确状态。SEO 与 AI 检索应建立在这类有用内容上，索引和排名无法保证。
