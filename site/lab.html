Try a causal comparison

  1. Load the real circuit. Select looming_left, apply a 100 ms stimulus, then run. Observe the GF group and output.
  2. Reset, silence “All output neurons”, and repeat the same stimulus. Input populations can respond while new GF spikes are suppressed.
